Teen Patti sequence list — which sequence beats which

A sequence (run) is three consecutive cards. Here's every run ranked from highest to lowest, and the rule for comparing two of them.

Pure sequence vs sequence

A Pure Sequence is three consecutive cards of the same suit (a straight flush) — like . A plain Sequence is three consecutive cards of mixed suits. Any Pure Sequence beats any plain Sequence; among themselves, both follow the same order below.

Sequences, highest to lowest

A-K-Q is the top run. A-2-3 () comes next — it's a valid run and, in most house rules, ranks second. After that, runs rank by their top card down to 4-3-2.

  2. A-2-3

Comparing two sequences

Find each hand's run in the list above; the one higher up wins. Two players can't hold the same run in the same suits, so a Pure Sequence never ties another Pure Sequence.

House rules vary on exactly where A-2-3 sits — some rank it as the lowest run instead of the second-highest. Agree this before you play.
